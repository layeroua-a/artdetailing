# Art Detailing — сайт

## Как запустить локально

Файлы статические, но лучше открывать не двойным кликом, а через локальный
сервер (иначе в некоторых браузерах могут быть проблемы с шрифтами).

Если есть Python:

```
cd art-detailing
python3 -m http.server 8080
```

Затем открыть в браузере: http://localhost:8080

Если есть Node.js:

```
npx serve .
```

## Структура

```
index.html          — главная (RU)
pricing.html         — цены
gallery.html         — галерея работ
faq.html              — вопросы и ответы
about.html            — о нас
contacts.html         — контакты
ua/                   — украинская версия всех тех же страниц
assets/css/style.css  — все стили
assets/js/main.js     — вся интерактивность (меню, табы, слайдер до/после, форма и т.д.)
build.py              — генератор страниц (не обязателен для запуска сайта,
                         нужен только если захочется поменять тексты через код)
```

## Как выложить на GitHub Pages, чтобы всё точно заработало

1. Файлы из этого архива (включая скрытый файл `.nojekyll`!) должны лежать
   **прямо в корне репозитория**, а не во вложенной папке. То есть в корне
   репозитория сразу должны быть видны `index.html`, `assets/`, `ru/` и т.д.
   Частая ошибка — залить папку `art-detailing` целиком как подпапку, тогда
   сайт окажется по адресу `.../art-detailing/`, а не в корне.
2. В репозитории: **Settings → Pages → Source** — выбрать ветку (обычно
   `main`) и папку `/ (root)`, сохранить.
3. Подождать 1–2 минуты и открывать именно ссылку вида
   `https://имя-пользователя.github.io/имя-репозитория/` (её показывает
   GitHub в том же разделе Pages) — а не страницу файла на github.com.
   Открытие `index.html` через обычный просмотр файла на github.com не
   запускает сайт, там просто показывается код.
4. Файл `.nojekyll` в корне обязателен — без него GitHub иногда по-своему
   обрабатывает статические сайты и может не отдавать часть файлов.
5. Если после этого что-то всё равно не работает — открой сайт в браузере,
   нажми F12 (консоль разработчика) и посмотри, нет ли красных ошибок на
   вкладке Console — это подскажет, какой файл не подгрузился.
