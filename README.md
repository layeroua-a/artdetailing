# Art Detailing — сайт

## Как запустить локально

Файлы статические, но лучше открывать не двойным кликом, а через локальный
сервер (иначе в некоторых браузерах могут быть проблемы с шрифтами).

Если есть Python:

```
cd art-detailing
python3 -m http.server 8080
```

Затем открыть в браузере: http://localhost:8080

Если есть Node.js:

```
npx serve .
```

## Структура

```
index.html          — главная (RU)
pricing.html         — цены
gallery.html         — галерея работ
faq.html              — вопросы и ответы
about.html            — о нас
contacts.html         — контакты
ua/                   — украинская версия всех тех же страниц
assets/css/style.css  — все стили
assets/js/main.js     — вся интерактивность (меню, табы, слайдер до/после, форма и т.д.)
build.py              — генератор страниц (не обязателен для запуска сайта,
                         нужен только если захочется поменять тексты через код)
```

## Где сейчас заглушки, что нужно будет заменить

- **Фото и картинки** — сейчас везде вместо реальных фото стоят красивые
  плейсхолдеры (тёмно-зелёные/светлые плашки с иконкой машины). Как только
  пришлёшь фотографии — заменю их на реальные фото в галерее, услугах,
  команде и т.д.
- **Телефоны, адрес, соцсети** — стоят заглушки (`+38 (067) 000-00-00`,
  «Киев, ул. Примерная, 5» и т.п.) — поменяем на настоящие.
- **Цены** — ориентировочные, для примера. Пришли реальный прайс — заменю.
- **Карта на странице контактов** — сейчас плашка-заглушка, потом можно
  вставить настоящую карту (Google Maps / Google Maps embed).
- **Форма заявки** — сейчас работает только «на фронте»: после отправки
  показывает «Спасибо», но никуда реально не уходит (нет бэкенда). Когда
  определимся, куда должны прилетать заявки (Telegram-бот, почта, CRM) —
  подключим.
